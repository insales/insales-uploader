# Переход на InSales Uploader 2

Версия 2 требует Node.js ≥22.18. CommonJS, фабрика с `new` и без него, `insales-config.js` / `.json` и основные команды CLI сохранены. Пользователю не нужны TypeScript, Babel или сборка самого пакета.

## Готовые файлы вместо Gulp

Удалены `src()`, `dest()`, `watch(paths, streamFiles)`, `triggerFile()` и весь раздел конфигурации `plugins`, включая `plugins.exclude`. Конфиг с полем `plugins` завершает запуск ошибкой до обращения к магазину. Удалите поле целиком, даже если оно пустое.

`plugins.exclude` раньше исключал файлы из обработки плагинами, а не из загрузки. Не переносите его автоматически в `theme.excludeFiles`: иначе нужные `.min.js`, `.min.css` или `.liquid` перестанут отправляться при наблюдении.

Компиляцию и минификацию запускайте в проекте темы отдельно. Например, при конфиге в `theme/` с `theme.root: '.'`:

```sh
# Сначала получить тему и подготовить её директории:
uploader --cwd theme download

# Терминал 1: внешний компилятор, установленный в вашем проекте:
sass --watch src/styles:theme/assets/style

# Терминал 2: uploader следит за готовыми файлами:
uploader --cwd theme stream
```

Исходники сборки держите вне наблюдаемых папок темы. Uploader не преобразует CSS/JS. `start()` по-прежнему сначала скачивает тему, а затем включает наблюдение; `stream()` включает наблюдение без скачивания. `stopStream()` закрывает watcher и дожидается уже принятых операций.

## Callback после успешной операции

`stream(callback)` и `theme.onUpdate` получают обычный объект:

```typescript
interface UpdateEvent {
  event: 'add' | 'change' | 'unlink';
  path: string; // абсолютный путь, разделители нормализованы в /
  asset: Asset; // локальные метаданные ассета
  insalesInfo: AssetInfo; // имя, тип и информация для API
}
```

Методов Vinyl, поля `contents` и `.pipe()` у события нет. Путь относится к изменённому файлу, в том числе к копии в `assets`. Зеркальная запись в `media/assets` не создаёт второй callback и повторную загрузку.

Сначала завершается запрос API, затем вызывается callback `stream`, затем `theme.onUpdate`. Callback может возвращать Promise. При ошибке загрузки success-callbacks не вызываются. Ошибки наблюдения логируются и доступны через событие `watchError`; следующие события продолжают выполняться. Автоматических повторов не добавлено.

```javascript
const uploader = require('insales-uploader');
const app = uploader(require('./insales-config.js'));

app.eventEmitter.on('watchError', error => console.error(error));
app.stream(update => console.log(update.event, update.path)).catch(error => {
  console.error(error);
  process.exitCode = 1;
});
```

Рецепт [BrowserSync](recipes/browsersync.md) продолжает работать через `theme.onUpdate`.

## CLI

- Сохранены команды и алиасы, `--cwd`, `--myappfile` и повторяемый `--require`. Модули `--require` разрешаются относительно рабочей директории и загружаются перед конфигом.
- Без `--myappfile` ищется `insales-config.js`, затем `.json`, начиная с рабочей директории и далее вверх. Относительный `theme.root` разрешается от рабочей директории; при необходимости задайте абсолютный путь.
- `uploader` без команды запускает `start`, как указано в справке проекта.
- Liftoff и `--completion` удалены. V8-флаги задавайте через `NODE_OPTIONS`.
- `init` не перезаписывает существующий конфиг. `--help` и `--version` работают без настроек магазина.

## Типы и внутренние модули

Пакет содержит `.d.ts`; из корня доступны `Options`, `UpdateEvent`, `UpdateCallback`, `AssetType` и `Instance`. Строковые и числовые идентификаторы поддерживаются. В ESM доступен default import той же CommonJS-фабрики.

Импорты внутренних файлов `dist/...`, внутренние очереди и устройство полей экземпляра не являются стабильным публичным API. Используйте корневой импорт и методы uploader. Алиасы `pullTheme()` и `pushTheme()` сохранены.

Семантика очереди сохранена: пакеты выполняются последовательно, Promise относится к своему пакету, ошибка останавливает остаток этого пакета, следующий пакет продолжает работу. Дедупликация оставляет последнюю задачу с заданным ключом внутри пакета; элементы без ключа сохраняются. Очереди разных экземпляров изолированы.

## Что продолжает работать

Скачивание отдельных типов ассетов, загрузка файлов аккаунта, бинарные данные, виджеты, ZIP-резервные копии, `skipUnchanged`, синхронизация `media/assets`, системные уведомления и открытие браузера сохранены. Правила удалений при `upload` и `pull` не изменены.
